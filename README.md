A structured collection of PyTorch implementations focusing on deep learning architectures, specifically tailored for **Image Recognition** tasks. This repo is designed to be modular, allowing for easy integration into larger systems or deployment via Docker.

---

## 🚀 Overview
This repository serves as a centralized hub for neural network models built using the PyTorch framework. It includes scripts for data preprocessing, model definition, and training loops optimized for high-performance image classification.

* **Core Framework:** PyTorch & Torchvision
* **Key Features:** Custom CNN architectures, Transfer Learning, and modular Data Loaders.
* **Environment:** Developed and tested in Google Colab and local Python environments.
